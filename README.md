# Fractal Lab

Локальный WebGL-редактор с десятью разными фрактальными мирами, непрерывным зумом, палитрами и экспортом PNG и видео. Без установки зависимостей.

## Запуск

```sh
npm run dev
```

Самостоятельно открыть http://127.0.0.1:5173. Нужны Python 3 и браузер с WebGL. Сервер не открывает вкладки автоматически.

## Сцены

1. Crimson Lace — спирали Julia, малиновая палитра.
2. Ocean Valley — Mandelbrot, холодные синие и бирюзовые оттенки.
3. Solar Flare — Burning Ship, огненные иглы.
4. Violet Mirror — Tricorn, тройная симметрия.
5. Jade Knot — Celtic, зелёные переплетения.
6. Copper Feather — Phoenix, медные ветвящиеся формы.
7. Electric Bloom — Multibrot третьей степени.
8. Prism Roots — бассейны Ньютона для z³ − 1.
9. Pearl Planet — трёхмерный Mandelbulb, ray marching, освещение и перспектива.
10. Golden Labyrinth — трёхмерная губка Менгера.

Три пересекающихся овала появляются внутри фрактального узора и его орбитальных преобразований. Регулятор «Овальные мотивы» меняет их выраженность. Надписей и водяных знаков бренда нет.

## Непрерывный зум

Камера использует иерархические координаты по основанию 16: адрес ячейки хранится в BigInt, а локальная координата и масштаб остаются в безопасном диапазоне. При приближении раскрываются новые процедурные уровни с плавным смешиванием. Нет минимального масштаба или автоматического возврата к старту. Обратный зум восстанавливает прежний маршрут.

Это многоуровневая художественная композиция на основе фрактальных формул, а не расчёт одной фиксированной области Julia или Mandelbrot с произвольной математической точностью. Периодические области и цветовые поля составляют процедурную среду. Два 3D-режима используют объёмный расчёт расстояний и света; их экранные проекции также участвуют в переходах между уровнями.

## Управление и экспорт

Перетаскивание — перемещение. Колесо, жест двумя пальцами и двойной клик — приближение к курсору. Пробел — полёт / пауза, R — сброс, F — полный экран. Доступны форматы 16:9, 9:16 и 1:1.

PNG: длинная сторона 3840 px. Видео: до 10 секунд, 1920 px, WebM / MP4 при поддержке MediaRecorder и canvas.captureStream. Результат экспорта зависит от возможностей браузера и видеокарты.

## Telegram и Open Graph

В `index.html` метаданные Open Graph находятся в исходном HTML и читаются без JavaScript. Картинка `preview.jpg` имеет размер 1200×630. Указаны размер, тип, alt, заголовок, описание и Twitter Card. Публичный адрес в метаданных: https://iamnhuman.github.io/fractal/ — при смене домена нужно обновить canonical, og:url и абсолютные URL картинки.

Telegram сможет показать карточку после размещения сайта по публичному HTTPS-адресу. На localhost карточка недоступна. Само отображение в Telegram в этой среде не проверяется.

## Проверки

```sh
npm run check
npm test
```

Тесты проверяют глубину более 10^1000, отсутствие сброса, переходы между уровнями, сохранение точки под курсором и обратный зум. `scripts/render-scenes.m` позволяет отдельно компилировать шейдеры и получать иллюстрации без браузера (macOS + Command Line Tools). Это не интерактивная проверка сайта; пользователь проверяет интерфейс в своём браузере.
