# Fractal Lab

Локальный WebGL-редактор с десятью разными фрактальными мирами, непрерывным зумом, палитрами и экспортом PNG и видео. Без установки зависимостей.

## Запуск

```sh
npm run dev
```

Самостоятельно открыть http://127.0.0.1:5173. Нужны Python 3 и браузер с WebGL. Сервер не открывает вкладки автоматически.

## Сцены

Восемь самоподобных множеств Julia: два квадратичных с разными параметрами и многочлены третьей–восьмой степени. У каждой сцены своя палитра и точка приближения. Pearl Lattice — объёмный фрактал Вичека, Golden Labyrinth — объёмная губка Менгера. Оба объёма вычисляются трассировкой лучей по рекурсивному полю расстояний.

Овальные мотивы участвуют в окраске по координатам орбиты и поверхности. Надписей и водяных знаков бренда нет.

## Самоподобное приближение

Видимое множество Julia задаётся одним фиксированным многочленом f(z) = z^d + c. Полёт направлен на его отталкивающую неподвижную точку a; множитель подобия λ = f′(a). Камера не дрейфует и не подмешивает новые картинки.

Для сохранения точности используется нормализованная координата Lₖ(q) = fᵏ(a + q/λᵏ) − a. Смена координат удовлетворяет Lₖ₊₁(λq) = f(a + Lₖ(q)) − a, поэтому сохраняется принадлежность тому же Julia-множеству. Первые 24 шага рассчитываются через факторизованную разность (a + δ)^d − a^d; дальше используется сходящаяся линейзация. Цвет и освещение компенсируют смену координат, вместо перехода между независимыми изображениями. Это приближение бесконечной самоподобной окрестности Julia, а не произвольная точность для любой выбранной вручную точки.

Объёмные сцены — фиксированные рекурсивные множества, самоподобные при увеличении в три раза. Вичек использует центральный крест, Менгер — угловую окрестность губки. Направление полёта остаётся на самоподобной детали. Число видимых итераций и точность экрана конечны.

## Управление и экспорт

Перетаскивание — перемещение. Колесо, жест двумя пальцами и двойной клик — приближение к курсору. Пробел — полёт / пауза, R — сброс, F — полный экран. Доступны форматы 16:9, 9:16 и 1:1.

PNG: длинная сторона 3840 px. Видео: до 10 секунд, 1920 px, WebM / MP4 при поддержке MediaRecorder и canvas.captureStream. Результат экспорта зависит от возможностей браузера и видеокарты.

## Telegram и Open Graph

В `index.html` метаданные Open Graph находятся в исходном HTML и читаются без JavaScript. Картинка `preview.jpg` имеет размер 1200×630. Указаны размер, тип, alt, заголовок, описание и Twitter Card. Публичный адрес в метаданных: https://iamnhuman.github.io/fractal/ — при смене домена нужно обновить canonical, og:url и абсолютные URL картинки.

Telegram сможет показать карточку после размещения сайта по публичному HTTPS-адресу. На localhost карточка недоступна. Само отображение в Telegram в этой среде не проверяется.

## Проверки

```sh
npm run check
npm test
```

Тесты проверяют функциональное тождество самоподобия, принадлежность точек тому же множеству и непрерывность окраски при смене координат, глубину более 10^1000, отсутствие дрейфа, точку под курсором, обратный зум и масштабную инвариантность объёмных полей. `scripts/render-scenes.m` позволяет отдельно компилировать шейдеры и получать иллюстрации без браузера (macOS + Command Line Tools). Это не интерактивная проверка сайта; пользователь проверяет интерфейс в своём браузере.
